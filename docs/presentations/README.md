# CareTranslate Studio Presentations

This directory contains presentation-ready summaries of the project for management,
security, privacy, legal, architecture, and delivery discussions.

## Available deck

- **[CareTranslate Studio executive overview](CareTranslate-Studio-Executive-Overview.pptx):**
  Seven-slide overview covering the product problem, current POC, end-to-end workflow,
  Azure Document Intelligence and Azure OpenAI exposure boundaries, proposed production
  architecture, processing profiles, evidence gates, and management decisions.

The deck includes source references in its PowerPoint speaker notes. It summarizes the
repository documentation but does not replace it. The authoritative requirements and
security decisions remain in `docs/PRD.md`, `docs/DATA-SECURITY.md`, and
`docs/ARCHITECTURE.md`.

## Maintenance rule

Update or replace the deck when a material product, security, architecture, provider, or
roadmap decision makes its visible statements inaccurate. Preserve the distinction between
the implemented synthetic-only POC and the proposed production target.
